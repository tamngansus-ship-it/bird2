# ระบบรับสมัครนักเรียน นักศึกษาใหม่ออนไลน์ครบวงจร
## วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์ (Thaluang Cementhai Anusorn Technical College - TTC)
สังกัดสำนักงานคณะกรรมการการอาชีวศึกษา (สอศ.) กระทรวงศึกษาธิการ

---

### ภาพรวมระบบ (System Overview)
ระบบรับสมัครเรียนออนไลน์ครบวงจรที่พัฒนาขึ้นเพื่อต่อยอดการทำงานของสถานศึกษา รองรับทั้งผู้สมัครเรียน (Front-end) และเจ้าหน้าที่งานรับสมัคร/ทะเบียน (Back-end) มีการเชื่อมโยงข้อมูลตั้งแต่การกรอกใบสมัคร ตรวจสอบเอกสาร การออกรหัสนักศึกษา การพิมพ์ใบมอบตัว และการส่งออกข้อมูลเข้าสู่ระบบฐานข้อมูล ศธ.02

---

### โครงสร้างและฟังก์ชันการทำงาน

#### 1. ส่วนสำหรับผู้สมัครเรียน (Front-end)
* **หน้าหลัก (index.html):** ป้ายประชาสัมพันธ์, ข้อมูลหลักสูตร ปวช./ปวส., ปฏิทินรับสมัคร, รายการเอกสารที่ต้องเตรียม และกล่องค้นหาสถานะด่วน
* **ระบบกรอกใบสมัครและตรวจสอบความถูกต้อง (apply.html):**
  - ฟอร์ม 5 ขั้นตอน (Wizard Form) พร้อม Progress Bar
  - **Data Validation เข้มงวด:**
    - ตรวจสอบเลขประจำตัวประชาชน 13 หลักด้วยสูตร Modulo 11 ของทะเบียนราษฎร์ ป้องกันการกรอกเลขผิด
    - ตรวจสอบเบอร์โทรศัพท์ 10 หลัก
    - Dropdown ระดับชั้น (ปวช./ปวส.) และสาขาวิชาสัมพันธ์กัน ป้องกันปัญหาชื่อสะกดไม่ตรงกัน
    - วันเดือนปีเกิด (พ.ศ.) และคำนวณอายุอัตโนมัติ
    - ตรวจสอบเกรดเฉลี่ยสะสม (GPAX 0.00 - 4.00)
* **ระบบอัปโหลดเอกสารหลักฐาน:**
  - รองรับ 4 ช่องทาง: 1) รูปถ่ายหน้าตรง 1.5 นิ้ว 2) สำเนาบัตรประชาชน 3) สำเนาทะเบียนบ้าน 4) ใบ รบ./ปพ.1
  - มีระบบ Drag & Drop, ตรวจสอบประเภทไฟล์ (JPG, PNG, PDF) และขนาดไม่เกิน 5MB พร้อมพรีวิวทันที
* **ระบบตรวจสอบสถานะการสมัคร (status.html):**
  - ค้นหาด้วยเลขบัตรประชาชน 13 หลัก หรือเลขที่ใบสมัคร
  - แสดง Timeline 4 ขั้นตอน: ยื่นใบสมัคร &rarr; ตรวจเอกสาร &rarr; ประกาศผล &rarr; มอบตัว
  - **ฟังก์ชันแก้ไขเอกสาร (Repair Re-upload):** หากสถานะเป็น "เอกสารไม่สมบูรณ์" จะมีกล่องให้อัปโหลดเอกสารใหม่ส่งตรงถึงเจ้าหน้าที่ทันที
* **ระบบดาวน์โหลด/พิมพ์ใบสมัครและใบมอบตัว (print-application.html):**
  - จัดหน้าพอดีกระดาษ A4 มาตรฐานราชการ (Print to PDF / พิมพ์ผ่านเบราว์เซอร์)
  - เอกสารใบสมัครเข้าศึกษาต่อ พร้อมรูปถ่าย, รหัสใบสมัคร, บาร์โค้ด และลายมือชื่อ
  - เอกสารใบมอบตัวและสัญญาค้ำประกันนักเรียนนักศึกษาใหม่ พร้อมข้อตกลงและพยาน 2 ท่าน

---

#### 2. ส่วนสำหรับเจ้าหน้าที่และผู้ดูแลระบบ (Back-end)
* **แดชบอร์ดสรุปสถิติแบบเรียลไทม์ (admin.html - Dashboard & Analytics):**
  - การ์ดสรุปยอด: ผู้สมัครรวม, รอตรวจสอบ, เอกสารไม่ครบ, ผ่านคัดเลือก, มอบตัวสำเร็จ
  - กราฟแท่ง (Bar Chart): ผู้สมัครแยกตามสาขาวิชา ปวช. และ ปวส.
  - กราฟโดนัท (Doughnut Chart): สัดส่วนผู้สมัคร ปวช. vs ปวส.
  - กราฟแท่งแนวนอน: สถิติโรงเรียนเดิมที่ส่งนักเรียนมาสมัครมากที่สุด
  - กราฟวงกลม: ช่องทางที่รู้จักวิทยาลัย / ผู้แนะนำแนะแนว
* **ระบบจัดการและตรวจสอบข้อมูลผู้สมัคร (Data Table & Filtering):**
  - ค้นหาแบบเรียลไทม์ (ชื่อ, นามสกุล, เลขบัตร, รหัสนักศึกษา, โรงเรียนเดิม)
  - กรองข้อมูลตาม ปีการศึกษา, ระดับชั้น, สาขาวิชา และสถานะ
  - Modal ดูรายละเอียดผู้สมัคร พร้อมแท็บดูเอกสารแนบทุกชิ้น และคลิกเพื่อขยายภาพ (Zoom Viewer)
  - Modal ปรับเปลี่ยนสถานะผู้สมัคร พร้อมกรอกบันทึกหมายเหตุ/เหตุผล และข้อความสำเร็จรูป
* **ระบบแจ้งเตือนอัตโนมัติ (LINE Notify / OA / Email):**
  - บันทึก In-app Notification Badge
  - จำลองและส่งข้อความแจ้งเตือนผ่าน LINE Notify และ Webhook ทันทีเมื่อมีผู้สมัครใหม่ หรือเมื่อเจ้าหน้าที่เปลี่ยนสถานะ
  - หน้าระบบตั้งค่า Token และกล่องบันทึกประวัติการส่ง (Dispatch Log)
* **ระบบออกรหัสประจำตัวและจัดการการมอบตัว:**
  - กำหนดรหัสประจำตัวผู้สมัครอัตโนมัติ (เช่น APP-68001)
  - กำหนดรหัสนักศึกษา 11 หลักมาตรฐาน สอศ. อัตโนมัติ (เช่น 68201010001)
  - บันทึกข้อมูลสัญญาการมอบตัว (ผู้ทำสัญญา, ความสัมพันธ์, พยาน 2 ท่าน, สถานะการชำระเงิน)
* **ระบบส่งออกข้อมูลมาตรฐาน ศธ.02 (Export Data):**
  - ส่งออกเป็นไฟล์ Excel (.xlsx แท้ ผ่าน SheetJS) หรือไฟล์ CSV (UTF-8 with BOM)
  - โครงสร้างคอลัมน์มาตรฐานงานทะเบียน 40 ฟิลด์ นำเข้าสู่ระบบฐานข้อมูล ศธ.02 ได้ทันที

### วิธีการเปิดใช้งาน
ระบบถูกพัฒนาเป็น Modern Web Application สามารถเปิดใช้งานได้ทันที:
1. ดับเบิลคลิกไฟล์ `index.html` เพื่อเข้าสู่หน้าเว็บไซต์หลัก
2. ดับเบิลคลิกไฟล์ `admin.html` เพื่อเข้าสู่ระบบจัดการสำหรับเจ้าหน้าที่ (มีข้อมูลจำลองของนักเรียนสระบุรี-ลพบุรี-อยุธยาให้ทดสอบทันที)
3. ดับเบิลคลิกไฟล์ `apply.html` เพื่อทดสอบการกรอกใบสมัคร
4. ดับเบิลคลิกไฟล์ `status.html` เพื่อทดสอบค้นหาเลขบัตรประชาชน (เช่น `1-1037-02584-12-9`)
5. ดับเบิลคลิกไฟล์ `print-application.html` เพื่อดูตัวอย่างใบสมัครและใบมอบตัวพร้อมสั่งพิมพ์ A4
